# Network Packet Sniffer

Консольная утилита на Python для перехвата сетевого трафика, сохранения дампов в формате `.pcap` и анализа захваченных пакетов.

## Возможности

* Захват сетевых пакетов в реальном времени и экспорт в `traffic.pcap`.
* Анализ готовых `.pcap`-файлов через флаг `--analyze`.
* Вывод основной статистики по протоколам, IP-адресам и портам.

## Требования

* Python 3.8+
* Библиотека для работы с пакетами (например, `scapy` — установите при необходимости через `pip install scapy`)

## Использование

1. **Анализ готового дампа трафика:**
   ```bash
   python3 sniffer.py --analyze traffic.pcap
   ```

2. **Захват трафика (запускать с правами администратора / `sudo`):**
   ```bash
   sudo python3 sniffer.py
   ```

## Структура проекта

* `sniffer.py` — основной скрипт сниффера и анализатора.
* `traffic.pcap` — файл с примером перехваченного сетевого трафика.
